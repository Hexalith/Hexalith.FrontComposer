Keyboard and announcement behavior

The preview uses the default polling and retry settings and default idempotent-confirmation copy. Hosts can configure them. The selector keeps keyboard focus as you inspect individual states. In the running shell, a meaningful transition is announced once for the active operation. Progress announcements coalesce over 250 ms. Routine polls and repeated terminal observations stay silent.
