## Problem

The form abandonment guard allowed navigation without showing its warning.

## Common Causes

- `AbandonmentGuardSuppressedWhileSubmitting` (6004) means the command was in the Submitting state.
- `AbandonmentGuardWrapperNavigationYielded` (6003) means the guard observed navigation flagged by the command lifecycle wrapper.

## How To Fix

Both paths are expected. Use the log event name to distinguish them when investigating navigation.

## Example

```text
HFC2103 Abandonment guard yielded for wrapper-initiated navigation. Target=/commands
```

## Suppression Guidance

Use a runtime logging filter if you do not need to observe expected abandonment bypasses.

## Migration/Deprecation

Use `FcDiagnosticIds.HFC2103_AbandonmentGuardSuppressed` when referencing the diagnostic from code. The earlier constant remains available as an alias.

## Related Diagnostics

None currently.
