## Problem

Shell denied presentation or execution of a protected command because the current authorization evaluation did not allow it.

## Common Causes

The user lacks the required policy grant, the session or tenant is unavailable, or the authorization check was canceled. Handler exceptions and other infrastructure failures have their own warning events.

## How To Fix

Read the structured `Reason` and confirm the expected policy registration and the user's current session and tenant. Use the digests to correlate related events.

## Example

Filter server logs for `DiagnosticId=HFC2123` or event `5672` (`AuthorizationBlocked`).

## Suppression Guidance

Keep denial telemetry available for operators and scope any log filtering to the specific diagnostic.

## Migration/Deprecation

Existing filters for event 5672 continue to apply.

## Related Diagnostics

None currently.
