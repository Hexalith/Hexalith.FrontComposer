## Problem

Invalid Level 4 view override component.

## Common Causes

SourceTools reports `HFC1043` at typed `AddViewOverride<TProjection, TComponent>()` calls when the component's `Context` is incompatible with the registered projection. The startup registry also validates descriptors from dynamic sources and generic registrations whose concrete types are only known at runtime. It ignores rejected descriptors so lower-level rendering can continue.

Reference `Hexalith.FrontComposer.SourceTools` as an analyzer in the project that contains the registration. For example, Counter.Web references SourceTools in addition to its projection project.

## How To Fix

Make the replacement a Blazor component with a public settable `[Parameter] ProjectionViewContext<TProjection> Context` property that matches the registered projection type and accepts a directly supplied value. Rebuild and rerun startup and tests after changing the registration.

## Example

```text
HFC1043: Invalid Level 4 view override component for projection OrderProjection. Expected: a component with [Parameter] ProjectionViewContext<OrderProjection> Context. Fix: update the replacement component or remove the descriptor.
```

## Suppression Guidance

Suppression is `allowed-with-rationale`. Prefer `.editorconfig` or a narrowly scoped pragma for analyzer diagnostics.

## Migration/Deprecation

Correct typed registrations that produce this warning. Valid registrations keep the same API and startup behavior.

## Related Diagnostics

None currently.
