## Problem

FrontComposer blocked a tenant-scoped operation because an identity segment was malformed.

## Common Causes

The default Shell resolver rejects colons and control characters in identity segments. It also rejects authenticated and requested tenant identifiers longer than 64 UTF-16 code units, and user identifiers longer than 1024.

## How To Fix

Check the host's identity mapping and any explicitly requested tenant. Supply the canonical identifiers from your identity provider within those bounds. Use the diagnostic's presence flags and correlation ID to troubleshoot without copying raw identifiers into logs.

## Example

```text
HFC2016: What: HFC2016 Tenant Context Malformed Segment. Expected: The Shell contract for HFC2016 is satisfied. Got: A bounded diagnostic payload identifies the affected FrontComposer surface. Fix: Apply the Shell remediation and rerun validation.
```

## Suppression Guidance

Suppression is `allowed-with-rationale`. Prefer `.editorconfig` or a narrowly scoped pragma for analyzer diagnostics.
