## Problem

A command property does not expose the public non-init setter required by generated assignment.

## Common Causes

The SourceTools producer emits `HFC1016` for any command property—derivable or user-editable—whose setter is absent, non-public, or `init`-only. Generated forms and derivable-value prefill both assign command members directly, so SourceTools suppresses command generation when this contract is not met.

## How To Fix

Change the reported property to a public `{ get; set; }` shape. Adding `[DerivedFrom]` does not make an incompatible setter valid because derivable properties are also assigned directly by generated code.

## Example

```text
HFC1016: What: Command property 'MessageId' is declared with an 'init' accessor. Expected: A public non-init setter. Fix: Change the property to '{ get; set; }'.
```

## Suppression Guidance

Suppression is `discouraged-error`. Prefer `.editorconfig` or a narrowly scoped pragma for analyzer diagnostics, and record migration or architecture rationale for Error-level suppressions.

## Migration/Deprecation

No migration action is required unless the registry later changes this diagnostic lifecycle.
